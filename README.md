# North Star Bakery Website

A semantic, fully accessible four page website built for North Star Bakery to promote handcrafted baked goods and collect pre orders.

## Pages Included
* index.html: Home page featuring a responsive picture element and baker audio greeting
* products.html: Product categories, pricing, and signature sourdough figure
* about.html: Bakery history, sourcing philosophy, and behind the scenes video tour
* contact.html: Pre order request form with built in validations

## Accessibility Features
* Strict logical heading structures
* Complete media fallbacks for audio and video elements
* Descriptive alternative text on all images
